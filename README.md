# Special Appreciation Cards ✨

Website apresiasi dan ucapan terima kasih untuk rekan-rekan tim. Dibuat dengan HTML5, Vanilla CSS (tema pastel aesthetic), dan Vanilla JavaScript.

## Fitur
- Kartu apresiasi interaktif dengan foto anggota tim.
- Pengamanan surat rahasia menggunakan tanggal lahir masing-masing rekan.
- Animasi ambient glow, efek transisi halus, audio chime, dan canvas confetti saat surat terbuka.
- Desain responsif di berbagai perangkat (desktop & mobile).
